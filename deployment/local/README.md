# 本机隔离部署：只读预检与验收入口

> **历史设计，2026-11-09起不再作为当前开发合同。** 用户已将数据安全职责交给IT源头/未来API，本目录的本机隔离前置要求由[ADR-0001](../../docs/adr/ADR-0001-DEVELOPMENT-AND-KNOWLEDGE-ARCHITECTURE.md)替代。目录和脚本仍在，代码迁移尚未完成；本轮未安装组件、修改系统配置或执行这些脚本。下文保留用于追溯，不能据此阻断当前开发或宣称生产隔离已验收。

用户目标：单机单操作者免登录，AI开发域、可信控制域、受保护执行域隔离；交付Excel＋RDS＋代码/证据包。**这里不是一键生产安装器，当前不允许接入真实数据。**

## 现有工具

- `preflight.ps1`：读取硬件、OS、Hyper-V管理命令与服务可用性，JSON输出。没有功能启用、软件安装、策略/注册表/网络/权限写操作。
- `verify-isolation.ps1 -Profile profile.example.json`：只检查Hyper-V配置观察值；VM名字是占位符，不自动创建。即使未发现配置问题，动态隔离仍是NOT_RUN，不输出“安全通过”。
- 输出仅到stdout；要保存报告，应由受信操作者选择位置。报告可含本机OS/VM信息，不默认送给模型或外部服务。

在项目根目录运行：

```bash
powershell.exe -NoProfile -NonInteractive -File deployment/local/preflight.ps1
```

```bash
powershell.exe -NoProfile -NonInteractive -File deployment/local/verify-isolation.ps1 -Profile deployment/local/profile.example.json
```

不使用ExecutionPolicy Bypass，不修改现有执行策略。执行策略/管理权限拒绝则记录未执行，不能换通道绕过。

## 2026-11-09 实测观察

约32GB RAM、8逻辑处理器、HypervisorPresent=true；Get-VM不可用，vmms未观察到。固件虚拟化/SLAT字段False，在已有hypervisor环境可能无法代表真实硬件能力，不能据此判定“不支持”或“已经可用”。两脚本实际输出productionDataEnabled=false，配置检查记录管理服务缺失和动态测试未执行。

## 必须另行批准的部署工作

1. 管理员核验Hyper-V可用性、磁盘空间、镜像来源/授权、宿主/guest系统和依赖版本；启用功能、下载镜像、重启均需明确授权。
2. 创建AI开发VM及受保护执行VM；明确可信Broker运行身份与密钥保管位置。生成程序/guest不能访问签名私钥。管理员受陷不在本系统绝对保证范围。
3. AI保留普通编程/批准模型网络能力，但无法访问原始数据卷、宿主共享路径、人类审阅服务、执行节点管理接口。禁止不必要的剪贴板/驱动器重定向、增强会话、共享文件夹、外设和guest服务入口。
4. 执行VM无网卡作为初始目标，无模型凭据，真实输入只读，结果/日志/临时目录/崩溃转储受保护；代码和投影经受控Broker传递。具体传输尚未实现，不为“免网卡”偷偷启用任意PowerShell/共享盘旁路。
5. 整个进程树终止/资源限制必须由执行节点实际保证；先完成合成负向测试，不能把父进程退出、签名字段或本机普通R执行等同证明。

## 请求与回执原语的边界

`plugins/dm-listing/src/protected/` 已有严格请求合同、Ed25519签名核验和SQLite防重放账本的合成验证。它们不是可运行的隔离worker、可信身份服务、OS沙箱或已部署Broker，不提供HTTP/模型工具入口，不加载/生成生产密钥。测试使用进程内临时密钥，不能据此说生产密钥隔离已完成。

请求中的approvalId/operatorId只是绑定字段；应由独立、可信UI/控制面鉴别和签发，模型不能通过填ID获得执行权限。节点回执由控制面固定keyId→公钥→nodeId验证；状态只有受信终态才能结算。断连保持UNKNOWN，过期不解锁，即使PASS/FAIL及摘要也默认仅本地审核，不直接进入模型。
