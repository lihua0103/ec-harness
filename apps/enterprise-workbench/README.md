# EMERALD 企业 AI 工作台

原生 ESM 前端，仅通过同源平台 HTTP API 工作，不包含假对话或模拟成果。首页提供最近工作、项目和待处理事项；项目可登记执行主机上的真实空间目录。新工作使用实际发布的应用及其元数据，分别记录短标题和完整目标。

工作详情分为对话、文件成果与运行历史，工程诊断折叠。工作和运行通过 `?work=<id>&run=<id>` 深链接；每个工作的草稿经服务端版本检查保存，冲突或失败时保留本地内容。模型目录与偏好由平台提供，执行器未配置时引导查看设置，不创建假排队。应用回应以文本形式呈现，不执行 HTML。

## API

前端使用 `/api/workbench`、`/api/projects`、项目空间、工作、草稿、运行、输入、问答、成果、模型及偏好接口。旧工作绑定空间需要 `PUT /api/works/:id/workspace`。具体权限与目录验证由平台服务负责；本地服务不是企业身份网关。

## 验证

运行 `node apps/enterprise-workbench/verify.mjs`，执行语法检查和纯状态/API 测试。测试不证明真实执行器、业务或部署验收。浏览器交互与真实平台接口需另行验收。
