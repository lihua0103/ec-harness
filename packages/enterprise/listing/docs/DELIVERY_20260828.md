### 15 个幸存 mutant 逐条归因

| # | 位置 | mutant | 归因 |
|---|---|---|---|
| 1 | worker `_write_audit` | mkdir(parents=False) | 父目录（项目根）恒存在（PROJECT_NOT_FOUND 前置守卫）→ 实际等价 |
| 2 | discovery `jsonable` | `is None or isinstance(bool,str)` → and | bool 落 int 分支、str 落 str() 回退，返回值恒等 → 等价 |
| 3 | discovery `_sheet_structure` | max(S-1, 0) → max(S-1, 1) | STRUCTURE_HEADER_ROWS=2 时 S-1=1 ≥ 1 → 恒等（随常量联动） |
| 4 | build_workbook `normalize` | 校验 Or→And | 空白名仍被后续"规范化后为空"拦下（fail-closed 语义不变，仅报错文案路径不同） |
| 5 | build_workbook `_row_counter` | itertuples(index=True) | 多重集比较两侧同移索引分量 → 计数不变式 |
| 6-9 | build_workbook `load_previous_version` | data_only / read_only / values_only / None-header 翻转 | 仅在业务页含公式单元格/None 表头时可观测；我们的业务页无公式（变化计数行为另由 vitest report 重跑为零测试守护） |
| 10 | build_workbook 标题带 | range(2, merge_end+2) | 第 7 列被重复补一次标题样式（同色系，仅字体差异）→ 纯外观冗余 |
| 11-13 | build_workbook 自定义页 | max(1,…) 地板 ×3 | 仅空帧/零列自定义 layout 有差异（退化输入） |
| 14 | build_workbook 自定义页 | band_index < → <= | 被 layout 校验（header_columns 行数 ≥ header_rows）保证不可达 |
| 15 | build_workbook 自定义页宽度 | len+2 → len+3 | 自定义页未给 column_widths 且长表头时列宽差 1 → 纯外观 |

无一条触及数据红线语义（行值/单元格值不出域、开关语义、fail-closed、
沙箱阻断、白名单键集合）。

### 变异测试过程中修复的真问题

1. `_sheet_structure`：`read_excel` 吞掉首行导致 rowCount 少 1、headerRows
   缺真实表头行（变异测试暴露边界后修正语义）；
2. 空表 `iloc[0]` 越界（结构扫描对 0 行 sheet 崩溃）；
3. `_sheet_rows` 截断后追加空行的边界（行级 break mutant 暴露）；
4. 测试方法论修正：边界常量必须断言**字面量**而非符号（mutant 改常量时
   两侧一起变），投影/过滤必须断言**对象恒等**（未命中红线 = 零改动）。

## 5. 残余风险与待办（显式接受 / 需用户在 Windows 侧执行）

1. **stdout 出域**（P0-2，2026-08-27/28 裁决显式接受）：run_code 内
   `print(datasets[...])` 经 stdout 回显——威胁模型为非对抗 AI；若未来要收，
   属另立场景，不偷加。
2. **表头带含首批 ≤2 行数据**（设计 §1 裁决 3）：多层表头识别需要。
3. **通用工具面**（read/bash 直读 csv）不属本插件（设计 §5.2），属 harness
   执行安全域。
4. G: 挂载无法 unlink——退役文件以 shim/标记形式存在，Windows 侧可直接删除：
   `python/redact.py`、`python/tests/test_redact.py`、`src/redaction.test.ts`、
   `tool-audit/src/data-interceptor.ts`。
5. git 提交需在 Windows 侧执行（沙箱 `.git/index.lock` 不可清理）。
6. worker spawn('python') 硬编码解释器（审计 P1-4）未处理——需 venv 策略决策。
