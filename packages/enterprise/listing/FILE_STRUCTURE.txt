核心功能文件地图
===============

1. 样式规范系统
   python/styles/style_spec.py
   ├── CONTENTS_SPEC (通用 Contents 页样式)
   ├── MANUAL_SPEC (蓝色主题)
   ├── MEDICAL_SPEC (绿色主题)
   ├── RBQM_SPEC (橙色主题)
   ├── REPORT_SPEC (蓝色主题)
   └── SYSTEM_FIELDS (系统字段定义)

2. 样式应用系统
   python/styles/formatter.py
   ├── format_contents_sheet() (格式化目录页)
   ├── format_data_sheet() (格式化数据页)
   └── format_workbook() (格式化整个 workbook)

3. Excel 生成系统
   python/styles/multi_sheet_writer.py
   ├── create_multi_sheet_excel() (主函数)
   ├── generate_contents_page() (生成目录)
   ├── calculate_changes() (计算变化)
   └── merge_listing_files() (合并文件)

4. Worker 集成
   python/worker_new.py
   ├── operation_publish() (更新：调用 multi-sheet)
   └── operation_merge() (新增：合并工具)

5. TypeScript 工具
   src/index_new.ts
   ├── enterprise_listing_publish (更新)
   └── enterprise_listing_merge (新增)


数据流图
========

用户代码
  │
  │ outputs = {"AE": df1, "VS": df2}
  │
  ▼
enterprise_listing_publish (TypeScript)
  │
  ▼
PythonWorker.request("listing_publish")
  │
  ▼
python/worker_new.py::operation_publish()
  │
  ├─ 重新执行用户代码获取 outputs
  │
  ▼
styles/multi_sheet_writer.py::create_multi_sheet_excel()
  │
  ├─ 1. load_previous_version()
  │    └─ 加载上一版本 (如存在)
  │
  ├─ 2. calculate_changes()
  │    └─ 计算新增/删除/修改
  │
  ├─ 3. 添加系统字段
  │    └─ Flag, Update Details, etc.
  │
  ├─ 4. generate_contents_page()
  │    └─ 生成目录 DataFrame
  │
  ├─ 5. pd.ExcelWriter() 写入所有 sheets
  │    ├─ Contents
  │    ├─ AE
  │    └─ VS
  │
  └─ 6. formatter.py::format_workbook()
       │
       ├─ format_contents_sheet()
       │    └─ 应用 CONTENTS_SPEC
       │
       └─ format_data_sheet() × N
            └─ 应用场景样式 (MANUAL_SPEC/MEDICAL_SPEC/etc.)
  │
  ▼
输出: {SCENARIO}_LISTINGS.xlsx
  ├─ Contents (目录页，含统计)
  ├─ AE (样式化数据页)
  └─ VS (样式化数据页)


部署文件映射
============

部署前:
  python/worker.py      → 当前生产版本
  src/index.ts          → 当前生产版本

部署后:
  python/worker.py.backup  ← 自动备份
  src/index.ts.backup      ← 自动备份
  python/worker.py         ← worker_new.py 内容
  src/index.ts             ← index_new.ts 内容
