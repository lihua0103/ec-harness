## 1. 决策与范围

**废弃“发现一个词，就在全文替换这个词”的执行合同。模型只提议候选；只有通过版本化策略、定位和校验的原文位置，才允许写回。** 同一字符串既可以是字段标签、普通术语，也可以是敏感值。保护针对结构与单次出现的位置，不用全局词黑名单代替结构。

- 目标：只改应改的敏感值或正文实体，保留键名、标签、表头、单位、章节标题和正常文意；输出可复核，不能把未检查范围当作通过。
- 非目标：不迁云、不换模型作为前置、不承诺所有格式一次上线、不承诺真实文件零风险或已经匿名化。替换后仍可能因上下文或可逆映射而重新识别。
- 范围：先重构现有本地工具，不新增独立的 DSH 产品运行面。若后续接入企业平台，按 [DSH 开发规范](DSH-PLUGIN-DEVELOPMENT-STANDARD.md)核对锁定版本公开契约，在 DSH 插件边界集成；本稿不宣称已完成上游适配。

## 3. 目标架构与唯一写入路径

```text
本地导入 → 格式适配器：原文结构 + 可逆定位 + 覆盖清单
                      ↓
          已知字段策略 / 规则 / 千问 1.7B（只产生候选）
                      ↓
           位置裁决：保护区、类别、边界、重叠与复核
                      ↓
          不可变替换计划 → 适配器写入临时成品
                      ↓
          独立复验：应改已改、不应改未动、覆盖完整
                      ↓
         工作台：可导出 / 待复核 / 不支持 / 失败
```

保留一个本地工具的部署形态：Node 负责运行编排、策略和模型调用，Python 负责格式解析、定位映射、写回与格式级验证；不另设微服务或数据库。模型和规则都没有改文件、调整策略或发布成品的权限。UI 显示状态但不能越过写回和导出门禁；CLI 与 UI 共享同一门禁。

### 核心合同

| 数据 | 必含信息 | 不变量 |
|---|---|---|
| `DocumentIndex` | 源文件摘要、适配器版本、格式、容器 ID、结构角色、原始内容及定位、覆盖清单 | 归一化只用于定位，必须能回投到原始字符；禁止跨单元格、双栏或不连续块拼接。无可靠位置即不允许自动写。 |
| `Candidate` | 容器 ID、原文引文、类别、来源、证据状态 | 规则可给精确区间；模型无需计算偏移，由程序在该容器内定位。多处同词定位不唯一时不猜。模型高置信或多针一致都不是写入授权。 |
| `Decision` | 每个候选的精确位置、策略版本、自动接受/拒绝/待复核及理由 | 禁写结构优先；明确字段策略优先于形状匹配；证据冲突待复核。不能靠“最长先改”吞掉异类候选或标签。 |
| `PatchPlan` | 源摘要、策略/适配器版本、每个位置的半开区间、预期原文校验、替换值 | 同一容器内跨度不重叠。文档/配置变化使计划失效。写回只认计划，不接受字符串映射；空替换须是明确策略动作。 |
| `Verification` | 应用位置数、非目标变化数、遗漏/覆盖状态、失败原因、成品摘要 | 重新打开成品验证，不信任写回自报计数。任何可导出成品必须与被验证摘要一致。 |

内部跨度统一使用**容器内 Unicode 码点半开区间**，边界不能切开组合字形；JS/Python 和格式坐标的转换在适配边界显式完成并测试。一个实体跨 Word run 或 PDF 折行可以对应多个物理区域，但仍是一条逻辑补丁。所有补丁对同一原始快照计算；禁止把本轮产出的占位符再送入同轮匹配。

### 业务策略如何裁决

- 结构键、标签、表头默认禁写。例如 `研究中心：` 整段保留，右侧仅在值区判断机构。单纯的标题 `研究` 不因分类模型输出而成为可写位置。
- 确认是项目敏感字段才启用对应操作。例如受试者日期、项目日期和公开参考版本分别配置；不能因像日期就修改。日期偏移需验证真实日历、保留约定精度与必要时间间隔；无法保留时不静默补造日期。
- 正文不是“全部保护”也不是“全可替换”。按上下文逐处识别实体；不明确的范围在本地复核。规则与模型重复指向同一位置可以合并证据，同词异处不能合并授权。
- 占位符在约定范围内保持一致，默认不跨项目关联。同一实体可复用同一代号，但占位符分配与位置授权是两件独立的事。跨文档一致性是显式项目设置，不作为默认行为。

## 4. 格式适配与覆盖声明

| 格式 | 定位与写回 | 未覆盖如何处理 |
|---|---|---|
| JSON、CSV/TSV、带标签的纯文本 | 对 JSON 仅对已授权的值 token 写回，支持嵌套、数组和转义；CSV/TSV 依结构解析表头、引号、字段和行；纯文本只识别明确标签或有证据的正文区间，不假定任意冒号都是键值分隔。 | 重复 JSON 键、编码不明、无法可靠划分的结构显式标注；不回退全文替换。 |
| Word、Excel | Word 以段落、run、表格等锚点写回；Excel 以工作表和单元格处理，默认保护表头、公式和非目标单元格，验证工作簿仍可打开。 | 页眉页脚、隐藏工作表、批注、修订、公式缓存、嵌入对象等需逐项声明：已验证、策略允许移除、或未支持。不能把“只处理可见内容”当整份通过。 |
| PDF | 建立页、块、字符和坐标映射，限制在已验证的逻辑阅读流内；实际清除已批准区域的原内容，不只盖图层。写回后同时验证文本/对象与页面像素，以及许可区域外的变化。 | 扫描页、混合页按页识别；图像 OCR、附件、表单、批注或未知对象未覆盖则阻断整份可导出。不能把栅格化后无法搜字作为通过证据。 |

每个适配器单独取得验收资格；未通过的格式不在新流程中标记可导出。不得为未支持格式保留旧全局替换作为兼容后门。

## 5. 千问 1.7B 的位置与评估

保留本地 1.7B 作为候选生成器：结构上能确定的字段不交给模型猜；正文模型输入按段落或连续版面组成短窗口，带容器 ID 和类别定义；输出约束为 `容器 ID + 类别 + 原文引文`，允许空候选。如果本地推理端支持结构化约束，优先使用；无论是否支持，消费端都必须严格校验。文档文字一律是数据，不能更改策略或指令。

记录模型版本、推理参数、模板版本以及每窗口完成状态；超时、截断、无效响应不得当作“无候选”。多针默认不是上线前提：在同一留出测试集比较规则、规则＋单针、规则＋多针的分类型新增召回、误报、复核量与耗时，再定默认值。只有证据表明某类持续漏识别，才考虑调整窗口、类别策略或更换该类识别器。真实项目试验仅在本机运行，对外仅记录经确认的聚合统计。

## 6. 作业状态、隐私与导出

- `可导出`：所有要求覆盖的范围有证据，计划完整且独立验收通过。零候选只有在覆盖完整且验证通过时才可解释为无策略命中。
- `待复核`：存在未决候选、不完整识别、局部覆盖未知或清除/保留证据不足。保留本地诊断或差异预览，但不走正式成品下载。
- `不支持`：格式或必要内容无法可靠解析或验证；`失败`：源文件变化、写回错误、校验错误等硬错误。不得静默降级，重新运行须重校计划。
- 原件只读。输入、索引、原值映射、拒绝明细与预览同属敏感资产；使用本地受控作业目录、最小访问权限和明确保留期，覆盖异常退出后的清理；默认不输出含原值的映射或报告，不上传日志或正文。导出仅包含已验收成品与不含原值的验收摘要。
- 用户可在本地复核一处差异或处理未覆盖项；复核是解决不确定性，不是跳过验证的按钮。复核后的计划仍走同一写入、验证和导出链。
